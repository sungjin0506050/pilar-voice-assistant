# 아이트래커 아이디어 (노트북 프로젝트용)

필라르와는 별개. 노트북에서 진행 중인 아이트래커 프로젝트에 추후 반영할 메모.

## 세션 / 기록 시작

- 기록(세션) 시작 시 진행 시간 선택 가능해야 함
- 선택지: **1분 / 3분 / 5분**
- **5분이 완전 상한** — 그 이상은 없음
- 이유: 아동 대상이라 피로도가 높음. 5분도 실무에서는 거의 안 씀 (무리)

## 분석 방식

- **화면 녹화**를 통한 분석으로 진행
- 웹캠/시선 원본만이 아니라, 사용자가 본 화면을 녹화해 그 영상으로 분석

## 녹화 영상 보관

- 녹화된 영상이 모이는 **전용 폴더**를 따로 두기
- 그 폴더에서 녹화본을 바로 열어 확인할 수 있게 하기

## 시지각 장애 유형별 프로그램 / 검사

- **시지각 장애 유형별**로 프로그램·검사를 따로 제작하는 방향
- 유형마다 과제·자극·분석 기준을 맞춰 구성
- 우선 넣을 검사 유형:
  - **얼굴실인증**
  - **색실인증**
  - **실독증**
  - **동시실인증**
  - **시각물체실인증** (시각유체실인증)

### 동시 / 한 세션 병행

- **진짜 이중과제(두 검사를 동시에 요구)** 는 아동·피로도 때문에 비추천 — 실패 원인이 섞임
- **한 녹화·한 자극 세트로 두 지표를 같이 보는 병행** 은 가능

가능에 가까운 조합:
- **얼굴실인증 + 시각물체실인증** — 얼굴/물체 시행을 번갈아 (이중해리 비교). 1~3분에 잘 맞음
- **동시실인증 + 시각물체실인증** — 여러 물체가 있는 장면 하나로 “전체 파악”과 “개별 인식”을 같이 관찰 (해석 시 주의)
- **색실인증 + 시각물체실인증** — 같은 물체에 이름/색을 순서대로 묻기 (진짜 동시 X, 짧은 연쇄 O)

비추천:
- **실독증 + 동시실인증**을 한 과제에 섞기 — 둘 다 “여러 요소”라 원인 구분 어려움
- **실독증**은 자극이 글자라서 다른 유형과 자극 세트를 공유하기 어려움 → **단독 짧은 블록**이 나음
- 한 세션에 유형 **3개 이상** 넣지 않기 (1~5분 상한)

## 이후 단계: 증상별 검사·추측 도구

- 각 증상(얼굴/색/실독/동시/물체실인증)마다 **검사 + 결과 추측(스크리닝) 도구**를 나중에 만들기
- 확진이 아니라 **경향·가설 제시** 수준으로 (전문가 해석용)
- 입력: 과제 반응 + 화면 녹화(시선/탐색 패턴)
- 출력: 해당 유형 가능성 메모 / 다시 볼 구간 표시 정도부터
