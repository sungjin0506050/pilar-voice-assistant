# 아이트래커 아이디어 (노트북 프로젝트용)

필라르와는 별개. 노트북에서 진행 중인 아이트래커 프로젝트에 추후 반영할 메모.

## 세션 / 기록 시작

- 기록(세션) 시작 시 진행 시간 선택 가능해야 함
- 선택지: **5분 / 10분 / 20분**

## 분석 방식

- **화면 녹화**를 통한 분석으로 진행
- 웹캠/시선 원본만이 아니라, 사용자가 본 화면을 녹화해 그 영상으로 분석

## 녹화 영상 보관

- 녹화된 영상이 모이는 **전용 폴더**를 따로 두기
- 그 폴더에서 녹화본을 바로 열어 확인할 수 있게 하기

## 시지각 장애 유형별 프로그램

- **시지각 장애 유형별**로 프로그램을 따로 제작하는 방향으로 검토
- 유형마다 과제·자극·분석 기준을 맞춰 구성 (세부 유형 목록은 추후 정리)
